# 1. Ontology of methods

The 16 methods go into three branches and six classes. The item number is the number of the method in the source list. Branch I decreases the text that goes into the context. Branch II tells who does the work and in which sessions. Branch III gives memory between sessions. Section F2 has no row, because it has no item in the source list, and sections F1 and F3 are one method (item 12). Items 1 and 17 of the source list name RTK and Context Mode. This guide keeps their goals and uses other means (section B, "Why this guide does not use RTK and Context Mode").
